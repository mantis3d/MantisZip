# 唯一根目录处理（压缩去目录 / 套根 + 解压剥根）

> **状态**: 🚧 进行中（2026-11-12 开工，v0.5.8 唯一一项） | **工时**: 约 10–16h | **来源**: [GitHub issue #35](https://github.com/mantis3d/MantisZip/issues/35)
> **定位**: 压缩设置窗新增「包内根目录」三态选项 + 解压设置窗新增「去掉压缩包顶层目录」开关，均默认关闭（原样），不影响现有所见即所得习惯
> **阶段归属**: 2026-11-12 单开 **v0.5.8** 只做本项（用户拍板）；原 v0.5.8「拖拽收尾与碎片清仓」顺延为 v0.5.9，其后两段依次 +1（队列 → v0.5.10、新功能与债务 → v0.5.11）

## 一、背景

issue #35（报告人 peter8777555）缠了两条线：

- **线 1（本计划）**：「唯一根目录」可选处理——压缩时可以「不包含所选目录本身」或「给多项套一层唯一根目录」；解压时可以「去掉压缩包顶层那层多余目录」。报告人本人是所见即所得习惯、明确不会用，只要保证**默认行为不变**（插件式选项）。Bandizip 已有同类功能。
- **线 2（选择器手势，不在本计划）**：Ctrl+A 后还要点「添加所选」的两步吐槽——**已由 2026-11-03 的 `checkbox-mode-consistency`（v0.5.6）解决**（Ctrl+A 全选后点组内任意一行复选框即整组打勾；右键「勾选所有可见项」）。issue 回复闭环由 maintainer 自行处理。

**与既有功能的边界**：智能解压（smart-extract，✅）是右键入口的**自动判定**（单根 → 剥离 / 散装 → 建包名目录）；本计划是解压设置窗里的**手动强制开关**，二者共享同一个「唯一根判定」，不另起一套。`extract-preserve-full-path-toggle` 管的是「条目完整路径 vs 解到目标目录」，与本开关正交（两个独立开关并存，剥根 + 保留完整路径可同时开）。

## 二、设计决策（用户逐项确认，2026-11-10）

| # | 问题 | 定案 |
|---|------|------|
| 1 | 压缩端形态 | **三态选择组**：`原样 / 去目录本身 / 套唯一根目录`，默认「原样」；不做两个独立 checkbox（避免组合出非法态） |
| 2 | 「套根」根名 | **输入框，默认值为压缩包文件名**（`archive.7z` → 包内根 `archive/`），用户可改 |
| 3 | 解压端「包顶层无唯一根」时 | **置灰**（不弹 NotStarted 提示）。「唯一根」判定复用智能解压已有判定 |
| 4 | 默认值持久化 | 与其它压缩/解压设置选项一致：**设置窗每次加载默认、确认不回写**；默认值在主设置窗口改（新增 `AppSettings` 默认值项，当次提交必须接上消费者——settingswiring 守卫） |
| 5 | 「去目录本身」多源场景 | **仅单目录源生效**：Sources 恰好是一个目录时可用，多目录 / 文件+目录混合时置灰（避免子项同名碰撞与起算点歧义） |
| 6 | `OutputMode = Separate`（每源一包） | 「套根」**置灰**（根名与各包同名、无意义）；「原样 / 去目录」仍可用 |
| 7 | GUI / CLI | 首版只做 GUI（右键 / 拖拽 / 对话框流程都经设置窗，覆盖即可）；CLI 参数列为后续（见「范围外」） |

### 三态语义定义

| 三态 | 条件 | 包内效果（相对现有「原样」的差异） |
|------|------|------|
| 原样 | 恒可用 | 现状不变 |
| 去目录本身 | **Sources 恰为一个目录**（否则置灰 + ToolTip 说明） | 该目录**不放进入包顶层**，其**直子项**直接落包顶层；子目录结构以该目录为基准整体保留；空目录 / 隐藏项行为与普通压缩一致 |
| 套唯一根目录 | `OutputMode != Separate`（否则置灰 + ToolTip 说明） | 全部源条目统一加一层 `<根名>/` 前缀；根名输入框默认 = 压缩包文件名（去扩展名） |

**叠序（硬约束）**：先做结构调整（展开目录 / 加根前缀 → 决定包内 entry 名），**再做** Filter 过滤与 Plan 白名单；否则过滤路径要重算两遍。

## 五、验收口径

1. 默认行为零变化：三态为「原样」、解压开关关时，所有现有流程（含智能解压）结果与改动前逐字节一致；
2. 「去目录本身」：选中 `7zip` 目录压缩 → 包内无 `7zip/` 层、子项结构与目录内一致；Sources 有多个目录或混合源时该选项置灰；
3. 「套唯一根目录」：选多项压缩 → 包内所有项都在 `root/` 下；Separate 模式下该态置灰；
4. 根名输入框默认包文件名，可改；改后包结构按新根名；
5. 解压「去掉顶层目录」：唯一根包→预览树与实解一致少一层；散装包→开关置灰无法开；
6. 重启应用后设置窗加载的是设置窗口里改过的默认值；单次运行的选择不回写；
7. `pwsh -File scripts\verify-repo.ps1 -Task check` / `-Task build -Target avalonia` / `-Target core`（若动 Core）/ `-Task test` / `-Task i18n` / `-Task guards` 全部通过。

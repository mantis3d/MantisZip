# MantisZip 手动测试清单（Avalonia 版）

> 适用对象：`MantisZip.UI.Avalonia`（主力版）。基线：v0.5.3（2026-10；含 alpha → beta 合并的压缩加速复核）。
> 测试人员逐条执行操作，在"实际结果"列填写观察到的行为，在"状态"列标记 ✅（通过）或 ❌（失败）。全部完成后汇总缺陷。

**备注列标注说明**：
- `[7z]` — 需 7z.dll（随应用分发）
- `[cascade]` — 右键菜单为"层叠模式"；`[verb]` — 动词模式（默认）
- `[drag-on]` — 需开启 设置 → 解压扩展 → 「拖拽导出」（EnableDragExtract）
- `[assoc]` — 需已安装对应格式的文件关联
- `[pwd-lib]` — 需密码库中存在匹配条目
- `[debug]` — 仅 Debug 构建可见（如测试菜单）

> **2026-10 重点**：alpha → beta 合并的压缩加速/编码/Deflate64 改动，见下方「3.7 压缩加速与自适应规则」。

### 3.7 压缩加速与自适应规则（2026-10 增量）

> 2026-10 在 alpha 分支完成并合并到 beta 的执行链改动。自动化已覆盖核心分支，但以下 GUI / 第三方工具 / 系统级占用场景仍需人工确认。

#### 3.7.1 魔数检测与自定义 MagicHex

| # | 操作步骤 | 前置条件 | 预期结果 | 实际结果 | 状态 |
|---|---|---|---|---|---|
| 1 | 设置 → 加速 → 格式目录新增格式：名称 `MyFmt`、扩展名 `.myd`、魔数 `4D5A`；再新增规则 `MyFmt → 仅存储`。准备 ≥64KB、以 MZ 开头的文件并改名为 `payload.dat`。压缩时开自适应 + 魔数 | — | `payload.dat` 按 Store 写入（7-Zip 查看方法 0 / 压缩后大小等于原大小） | | |

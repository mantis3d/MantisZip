压缩设置 ✕
简单 与 高级 的区别（计划第 2 条）
  • 简单：不显示复选框；单击选中、Shift 范围选；「当前目录选中项 = 结果」，切换目录会重置已选（覆盖语义）。
  • 高级：显示复选框；勾选跨目录记忆，切走再回来仍保持；下方「已选」是跨目录累积结果。
  • 两种模式下，下方「已选」都可逐项删除；点行可回到它所在目录并高亮。
本原型覆盖的计划点
  • ① 选择器内嵌进设置窗（不再弹窗）—— 见「添加文件 / 添加压缩包」页。
  • ③ 去掉右侧累积面板，改为下方「已选」列表，双向同步。
  • ④ 左侧 QuickPathControl（收藏 / 目录树 / 搜索），左右布局。
  • ⑤ 压缩窗 Tab 顺序：输出设置 → 添加文件 → 压缩设置 → 文件过滤。
  • ⑥ 解压窗对称：添加压缩包 / 输出设置；「选择要解压的文件」页支持按条目解压。

决策定案原型体现
①三态选择组（原样 / 去目录本身 / 套唯一根目录），默认原样压缩窗绿色框内的单选组
②根名输入框，默认包文件名，可改选「套根」时出现的根名字段（改包名联动默认值）
③解压端无唯一根 → 置灰，不弹 NotStarted顶部切「散装顶层包」看开关变灰 + 说明文字
④载入默认、确认不回写；默认在设置窗口改上方两块「主设置窗口」mock —— 或本页面刷新后压缩窗核对回「原样」的复位语义
⑤「去目录本身」仅单目录源生效，多源/混合置灰顶部切「多项混合源」看置灰门 ①
⑥Separate（每源一包）时「套根」置灰顶部切「每源一包」看置灰门 ②；预览变多包结构
⑦首版仅 GUI；CLI / COM 免窗直通列为范围外—（见计划 §六）
叠序硬约束（计划 §二）：先做结构调整（目录展开 / 根前缀 → 决定包内 entry 名），再做 Filter 过滤与 Plan 白名单；否则过滤路径要重算两遍。

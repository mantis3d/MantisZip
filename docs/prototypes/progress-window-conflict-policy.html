看点
  1. 下拉是唯一事实源：勾「应用到全部」不是写进看不见的记忆，而是把下拉同步成刚选的动作 —— 用户看得见、也能改回「每次询问」。
  2. 运行中切换立即生效：演示跑到一半直接改下拉，之后遇到的冲突立刻按新策略自动处理，已处理的条目不受影响（对应设计文档 §3.5 不变量）。
  3. 暂停 → 改策略 → 继续：在弹窗里点「暂停」，此时下拉可改；点「继续」后若下拉已是自动策略，不会再重弹同一个冲突（设计文档 §3.6）。
  4. 「每次询问」行为不变：默认档仍然弹现有 ConflictDialog（覆盖 / 覆盖较旧 / 覆盖较小 / 重命名 / 跳过 + 应用到全部 + 暂停 / 取消）。
  5. 两套档位：解压 6 档含「仅覆盖较旧 / 较小」；压缩 5 档含「追加到已有包」（不支持追加的格式会回退弹窗）。
  6. 布局取舍：独立行不挤按钮行；「信息区同行」— 密度靠左、冲突控件靠右，省一行高度、视觉最整合（代价是「视图密度」与「运行行为」混一行，500px 会折行）；底部行最像 TeraCopy 但在 500px 最小宽度下会挤。
  7. 视觉按真机语义走：主题画刷（ThemeSurfaceBgBrush / ThemeTextSecondaryBrush）与紧凑度资源键（ControlHeightLg / SpacingSm），不是写死像素。
